# Состояние проекта

Обновлено: 2026-10-02.

## Реализовано

- Laravel 13.34 / Vue 3 / TypeScript / Vite 8: строгие версионируемые документы, единый registry/renderer, RU/DE конструктор, autosave с UUID/revision, immutable releases, независимые копии, undo/redo и приватные заметки.
- Кабинет, пульт, ученик и проектор сохраняют занятия и ответы в БД. Работают совместное проведение с scoped grants, личные ответы ведущего, модерация и отдельная анонимная публикация, таймер, готовность/вопрос, роли, волна добра и возвращение в существующий класс.
- «Кто мой ближний?» v3 возвращает публичные русские формулировки OLD, 13 этапов, зелёную композицию, школьные переключатели, shuffled дорогу, личное решение, итог с тремя шагами и отдельное завершение. Однострочные ответы отправляются Enter; итоговое слово принимается до завершения. Подсказки текущего этапа и полный предоставленный план видны только ведущему.
- Роли доступны ученику по мере раскрытия ведущим. Школьный выбор направления сохраняется отдельно для каждого ученика. Полный собранный путь сохраняется после отправки; незавершённая последовательность остаётся локальным черновиком. Разбор показывает ошибки после раскрытия результатов.
- QR входа можно вывести крупно по центру общего экрана; кнопка «Общий экран» доступна в пульте. Сообщения выводятся поверх сцены крупной центральной карточкой. QR, сообщения и волна убираются при завершении.
- На заключительном экране ученика кнопка «Закрыть окно» вызывает browser close без перехода в каталог; если браузер запрещает закрытие, появляется инструкция закрыть вкладку вручную. У ведущего и проектора прежняя ссылка возврата сохранена. RU/DE UI переведён.
- Подложка правой подсказки ведущему остаётся прозрачной при наведении: перекрывающий общий button:hover больше не закрывает сцену. Browser CSSOM подтверждает alpha 0.27 в обычном и hover-правиле; frontend регрессия пройдена.
- Общий экран занимает всю ширину окна: приоритет CSS исправлен относительно прежнего `.public-session.projector { max-width: 1280px }`; браузер подтверждает computed max-width: none. Регрессия покрыта frontend-тестом.
- Главная без фильтров: единая граница текста/карточек, полноширинные фоновые секции и явный вход в кабинет. В каталоге фильтры представлены компактными native dropdowns. Предпросмотр личных и общих блоков открывается в modal dialog; формы и previews не показывают раздел авторства/прав. Прежние сохранённые metadata не уничтожаются.
- Корзина показывает дату/время удаления, восстановление, окончательное удаление и очистку подтверждённого набора до 100 копий. Окончательно удалённые копии нельзя восстановить или снова запустить; связанные версии, проведённые занятия и история сохраняются. Старые даты backfill основаны на прежнем updated_at, а не на вымышленной исторической дате.
- Незавершённое занятие можно завершить и убрать из активного списка, сохранив историю. История показывает именованные ответы непосредственно под вопросами, без пустых результатов обычных слайдов; после expiry персональные детали не выводятся.
- Библиотеки, медиатека, регистрация/verification/reset, гостевой claim, каталог pinned releases, административная проверка публикаций и восстановление snapshots действуют через существующие сервисы и проверки прав.
- Git-only deployment, additive migrations и read-only health/schema checks. Перед production migrations script проверяет private SQL/media backup и SHA256; production backup/retention schedules пока выключены.

- «Слова ранят. Слова лечат»: 16 этапов / 45 минут / RU и DE, восемь исходных иллюстраций, полный приватный план и подсказки, пять исходных русских DOCX/PDF/PPTX. Русские экраны и задания сверены с комплектом; DE включает онлайн-план, примеры, вопросы и варианты. Библейский DE текст обозначен как перевод предоставленного русского текста. Установка `lessons:install-words` атомарно добавляет урок и 17 RU/DE общих заготовок; повторный запуск проверяет receipt и SHA256, сохраняет скрытие, не переписывает прежние копии и занятия.
- Настройки последовательного открытия заданий, времени ответа и закрытия по таймеру доступны в конструкторе. Будущая фраза скрыта до разбора предыдущей; истёкший таймер блокирует ответы на сервере и после очистки. Личный выбор для недели сохраняется только в own answers без публичных кнопок/результатов. Общие заготовки содержат самостоятельные подсказки; в уроке подсказка расположена один раз на этапе.

- Комплект «Закхей. Можно ли исправить ошибку?» сохранён в `assets/lessons/zakkhei`: отдельная презентация на 12 слайдов и ZIP с полным сценарием, планом, паспортом, материалами учителя, раздаткой, описанием для сайта и четырьмя исходными иллюстрациями. Возраст 9–11 лет, 45 минут, Лк. 19:1–10. Ссылки для скачивания и состав комплекта приведены в README папки.

- Комплект «Не спеши судить» сохранён в `assets/lessons/ne-speshi-sudit`: паспорт, план, сценарий с готовыми репликами ведущего на 12 этапов, подготовка и подсказки учителю, раздатка, описание для сайта и четыре исходные иллюстрации в ZIP; PowerPoint на 12 слайдов доступен отдельно. Возраст 13–15 лет, 45 минут, Мф. 7:1–5. Ссылки и состав указаны в README папки.

## Важные решения

- V1/v2, прежние пользовательские копии и занятия остаются immutable. `lessons:upgrade-neighbor` безопасно перепривязывает только точный исходный каталог v2 к v3; для нового поведения нужен новый запуск/копия из каталога. Свежая установка: v1 → документация → `--revision=v2` → обычный upgrade v3.
- Ученические/проекторные DTO не содержат приватного плана, teacher notes или скрытых решений. Команды проверяют актуальные права, revision, UUID receipt и control epoch.
- Production: `/var/www/vhosts/lessons.atapin.de/httpdocs`, Plesk PHP **8.5.11** CLI/FPM (подтверждённое окружение этого проекта), Node 22.23.3, MariaDB 10.6.23, SSH :2377. Локально PHP8.4.25/SQLite/Node22.
- `.env`, credentials, локальные БД, логи, screenshots, backups и build не входят в Git.
