# Состояние проекта

Обновлено: 2026-10-01.

## Реализовано

- Этап 1: Laravel 13.34, Vue 3/TypeScript/Vite 8, строгий независимый домен документа версии 1 и три доверенных типа блока.
- Этап 2: гостевой кабинет RU/DE, редактор текста/изображения/вопроса, этапы и порядок, настройки, ручное сохранение и предпросмотр общим renderer.
- Этап 3: подготовка/начало, пауза/продолжение и окончательное завершение; независимый серверный таймер, сообщение на общий экран, ограниченная временем «волна добра», QR со ссылкой присоединения и индикатор активности участников.
- Удобный пульт: таймер/действия справа, прокручиваемый публичный preview в центре, сворачиваемые этапы; отдельное компактное окно/вкладка с подтверждением подключения, возвратом и восстановлением управления. Компактный пульт сохраняет заметки/решения/ответы без большого preview и глобального меню.
- Persistent LessonMaterial/LessonVersion: явная текущая версия, optimistic revision под row lock, immutable released-снимок, новый draft после правки выпущенного материала.
- Минимальное проведение: отдельное занятие на конкретной версии, пульт, код ученика, read-only проектор, участники и ответы. Переход назад сохраняет ответы; новые правки материала не меняют старый запуск.
- Сервер проверяет владение/участие; публичные экраны получают только активный этап без решений, заметок и чужих ответов. Правильные ответы видны отдельной карточкой только ведущему.
- Версионный manifest одного реального встроенного изображения, проверка точной пары asset/version и файла; загрузка медиа не имитируется.
- Additive migrations, readonly CLI checks БД/схемы, initial empty-schema deployment flag. Для непустой БД deployment --migrate создаёт приватный полный dump вне httpdocs перед миграцией; credentials не передаются в argv/environment и удаляются после работы. Реальный restore пока не проверен.

## Принятые решения

- Сначала движок и общие блоки; конкретные учебные темы не определяют архитектуру и пока не создаются.
- Языки UI и содержания независимы. Новый материал содержит текущий язык UI; существующие полные переводы редактируются/сохраняются. Добавление языка через UI и неполные черновики ещё не реализованы.
- Без регистрации владелец и участие связаны с серверной cookie-сессией браузера. После её истечения/удаления cookies восстановление доступа пока отсутствует; это ограничение явно показано в UI.
- Все запросы одной cookie-сессии сериализуются file lock; навигация/ответы — row lock занятия. Ответы не меняют revision команд учителя. Block ID сохраняется с binary collation для независимости Choice/choice в MariaDB.
- Polling раз в две секунды; клиент отбрасывает устаревшие результаты после команды. Ручное сохранение показывает conflict, не затирает локальные правки, предупреждает при уходе с несохранённым документом.
- Глобальное меню скрывается полностью. Отдельный пульт работает с тем же server state и cookie-доступом; браузерные окна не являются источником состояния/времени. Подключение окна подтверждается BroadcastChannel instance/heartbeat до скрытия встроенных кнопок; отсутствие/потеря подтверждения сохраняет либо возвращает управление.
- Команды учителя атомарны под row lock и имеют UUID/fingerprint/receipt. Повтор возвращает актуальное состояние без повторного действия; неподтверждённая команда сохраняет исходное тело для явного повтора. Пауза занятия и пауза таймера разделены; навигация не сбрасывает время/ответы, истечение таймера не завершает занятие.
- Для медиатеки владелец утвердил PNG/JPEG/WebP, 20 МБ на файл, 1 ГБ на аккаунт учителя, 100 МБ на гостя; загрузка ещё не реализована.
- Выпуск личной версии не публикует её в каталоге. Содержание и состояние проведения хранятся отдельно.
- Production по уточнению владельца: Plesk PHP 8.5.11 FPM/CLI, Node 22.23.3, MariaDB 10.6.23. Локально PHP 8.4.25/SQLite/Node 22.

## Проверки

- Полный Composer test/PHPUnit этапа 3: 130 тестов, 128 passed, 882 assertions, 2 Windows skips (POSIX permissions/symlink; проверяются Linux CI). Composer Pint, Vue typecheck, Vite production build и Bash syntax check прошли. Восемь frontend tests проверяют монотонный отсчёт, pending UUID/reload, устаревшие GET, handshake/heartbeat/возврат, срок wave и создание настоящего QR.
- Local additive migrations и lessons:check прошли. Проверены ownership/CSRF, immutable снимки, optimistic conflicts, invalid media/документы, изоляция занятий, ответов и проекций; MySQL/MariaDB migration DDL и case-sensitive ID покрыты.
- Браузер: создание → редактирование трёх типов → два этапа → сохранение/перезагрузка → запуск → проектор → вход/ответ ученика → навигация/возврат; ответ сохраняется, teacher получает его, закрытые заметки/решения отсутствуют на публичных экранах. Проверена неизменность старого запуска после новой правки, RU/DE и literal HTML как текст.
- Реальная ширина 360 px: редактор, пульт и ученик без горизонтального переполнения; 768/1366 px проверены. Меню открывается/полностью закрывается. Console errors при рабочем проведении не обнаружены.
- Этап 3 в браузере: prepared → begin → ответ → timer → pause/reload/resume; время и ответы сохраняются. Компактный экран 520/360 px без overflow/большого preview/главного меню. Popup handshake скрывает инструменты, возврат восстанавливает их; отдельный controller работает после закрытия основной страницы. Остановка локального HTTP-сервера блокирует действия, перезапуск восстанавливает состояние. Сообщение с HTML отображается текстом; wave доставляется ученику и не повторяется после reload. Отмена/подтверждение завершения, RU/DE и меню с клавиатуры проверены. Native popup не доступен для прямого управления CUA: его подключение/возврат наблюдались на parent, команды compact проверены отдельной авторизованной вкладкой; actual popup-blocker/browser matrix остаётся приёмке.
- GitHub CI implementation commit прошёл: PHP 8.4, PHP 8.5, frontend Node 22 и реальная MariaDB 10.6; run 36778205368.
- Production deployment fc75ab6 выполнен через Git: Composer platform requirements, Node typecheck/build, empty-schema preflight, additive migrations и lessons:check прошли. MariaDB 10.6.23, binary block ID collation подтверждены; /up, RU/DE кабинет и вход ученика — HTTP 200, .env/.git/исходник runtime — HTTP 404.
- Production браузер: три блока/два этапа созданы, сохранены, восстановлены после перезагрузки и запущены; UI/изображение/закрытая карточка ведущего работают, console errors отсутствуют. Проектор не показывает заметки/решения. После отдельного разрешения владельца тестовый ученик вошёл и ответил: ответ дошёл до пульта, переход вперёд и назад сохранил его. Данные других присоединившихся участников не изменялись.
- Реальная concurrent нагрузка MariaDB, полная browser matrix и backup restore не проверялись.
