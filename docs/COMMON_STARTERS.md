# Готовые общие заготовки RU/DE

После migrations этапа 8 доверенный оператор может выполнить:

```bash
php artisan lessons:install-common
```

Команда добавляет 16 настоящих переиспользуемых заготовок в существующую общую
библиотеку: приветствие, обсуждение милосердия, конкретные слова помощи,
безопасная помощь с выбором, опрос, парная инструкция, последовательность помощи,
итоговая рефлексия и восемь image-блоков из «Кто мой ближний?». Это отдельные
полные RU/DE блоки для конструктора, а не фиктивные готовые уроки.

У каждой заготовки стабильные UUID, immutable начальная версия и receipt
sourceRevision/SHA256 в attribution.installation. Повторный запуск не пишет
новые версии и сохраняет редакторские изменения, локализованные labels,
скрытие/архив и существующие экземпляры. Изменившийся источник, media bytes,
receipt или чужой stable ID блокирует установку целого пакета без overwrite.
Новая редакция набора должна иметь отдельную явно проверенную идентичность.

Installer использует действующие BlockRegistry/BlockInstance/LibraryMetadata,
MediaCatalogue и owner mutex, а данные сохраняет в существующие
BlockTemplateRecord/BlockTemplateVersion/CommonTemplate. Новая схема,
поддельный аккаунт администратора и отдельный движок не нужны. Обычная вставка
через общий API создаёт независимый instance с точным origin и сохраняет версии.
Учительские заметки и решения исключены из публичного preview.

Иллюстрации используют точные builtin-neighbor-* / *-v1 ссылки. Байты не
копируются; source/permission/неизвестный individual creator сохранены из
существующего manifest. Public-domain лицензия не заявляется. Текст — новая
редакционная заготовка, подготовленная с OpenAI по запросу владельца проекта.

Это новая команда наполнения. Наличие исходника и локальных tests не означает,
что набор уже установлен на production; это требует отдельного запуска команды
после Git deployment. Credentials и account admin grants команда не меняет.
