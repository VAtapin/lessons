# lessons.atapin.de

Главная, публичный каталог и урок «Кто мой ближний?» доступны на RU/DE. Каталог ищет по названию и фильтрует по возрасту, теме, аудитории, формату и длительности. Запуск создаёт отдельную копию и подготовленное занятие в кабинете; регистрация не обязательна. Выпуск личной версии сам по себе не добавляет материал в общий каталог.

Платформа интерактивных уроков. Реализованы основа, конструктор и проведение: редактор → сохранение → выпуск версии → подготовка/начало занятия → проектор → ответ ученика. Конструктор использует общие блоки текста, изображения, обсуждения, single/multiple-choice, опроса, письменного ответа, последовательности, соответствий, ролей и сигналов. «Кто мой ближний?» собран из этих блоков; дополнительные темы используют тот же движок.

Пульт поддерживает серверный таймер, паузу/продолжение и завершение, QR-вход, сообщения и «волну добра». Его можно открыть в компактном окне/вкладке; подключение подтверждается до скрытия встроенных кнопок. Реализованы личная библиотека заготовок блоков, версионная медиатека, аккаунт, история и закрытая репетиция. Реализованы совместное проведение с приглашениями, проверка предложенных публикаций, управление каталогом и общая библиотека блоков.

## Технологии и среда

- Laravel 13, PHP `^8.4` (локально проверяемая целевая версия — 8.4.25).
- Vue 3, TypeScript и Vite 8; Node.js 22 (ограничение проекта — `>=22.12.0 <23`).
- Постоянное хранение материалов, версий, занятий, участников, ответов, заготовок и метаданных медиа: MariaDB 10.6.23 на production, SQLite для локального запуска и тестов.
- Начальные словари интерфейса RU/DE задают языки UI, а не окончательный список языков содержания уроков.
- На production выбран Plesk с PHP 8.5.11 FPM и Node.js 22.23.3.

Локально нужны PHP 8.4 с требуемыми Laravel расширениями и `ext-gd`, Composer и Node.js 22. Для загрузки файлов: `upload_max_filesize` и `post_max_size` не ниже `32M`, `memory_limit` — `512M`; настройки CLI и HTTP/FPM проверяются отдельно. Используйте штатные команды и исполняемые файлы вашего окружения; абсолютные пути конкретной Windows-машины в инструкции не зашиты.

## Локальный запуск

Из корня проекта:

```bash
composer install
npm ci --ignore-scripts
cp .env.example .env
php artisan key:generate
php -r "file_exists('database/database.sqlite') || touch('database/database.sqlite');"
php artisan migrate
npm run build
php artisan serve
```

Приложение откроется по адресу, указанному Artisan (обычно `http://127.0.0.1:8000`). Используются файловые cache/session с блокировкой параллельных запросов одной сессии и синхронная очередь. Если PHP использует нестандартный `PHPRC`, запускайте `artisan serve --no-reload`, чтобы расширения были доступны дочернему серверу.

Кабинет: `/ru/studio` или `/de/studio`; присоединение ученика: `/ru/join` или `/de/join`. Регистрация необязательна. Гостевые материалы принадлежат серверной cookie-сессии: после её истечения/удаления cookies восстановление доступа пока не предусмотрено. `/ru/account` и `/de/account` позволяют работать с аккаунтом; перенос прежних гостевых материалов выполняется отдельно, целиком и только после подтверждения email. Новый материал создаётся на текущем языке UI; языки содержания добавляются и редактируются в конструкторе независимо от языка интерфейса. Рабочие незавершённые переводы сохраняются приватно, готовность каждого языка показывает сервер.

Автосохранение и кнопка сохранения записывают рабочий черновик, включая незавершённые переводы. Выпуск требует готового основного языка и выбранных полных переводов, фиксирует личную версию и не публикует её в каталоге. Занятие использует этот снимок независимо от последующих правок материала; переход назад сохраняет ответы. Ученик и проектор получают только публичное содержание активного этапа. Пауза занятия останавливает приём ответов и работавший таймер; отдельная пауза таймера сохраняет приём ответов. Истечение времени не завершает занятие. Закрытие любого окна также не завершает его.

## Библиотека и медиатека

Страницы `/ru/library`, `/de/library` открывают заготовки; `/ru/media`, `/de/media` — медиатеку. Заготовка копирует сохранённый блок своего материала со всеми переводами. Каждая правка создаёт immutable version; вставка даёт новый UUID и независимый экземпляр с точной ссылкой на исходную версию. Выбранные языки должны присутствовать в источнике, без автоматического fallback. Usage показывает ссылки из своих сохранённых draft/released-снимков.

Медиатека содержит 27 встроенных иллюстраций: 18 файлов `UI-Design`, одну сгенерированную иллюстрацию и восемь иллюстраций урока «Кто мой ближний?» из `OLD`. Manifest фиксирует точные пары asset/version. Собственные загрузки хранятся приватно в `storage/app/media`, без `storage:link`; замена файла создаёт новую immutable version, сохраняя старые ссылки и attribution. Обязательные метаданные фиксируют автора, источник, основание прав и условия использования. Архив обратим: скрывает новый выбор, но не удаляет версии, файлы или уже вставленные экземпляры.

Гость может загрузить до **20 MiB на файл** и **100 MiB суммарно**, аккаунт — до **1 GiB**, включая архивные версии. Проверяются MIME, декодирование GD, размеры и число пикселей. Авторизованный аккаунт сохраняет доступ после повторного входа; для гостя cookie-сессия остаётся единственным доказательством владения.

| API | Назначение |
| --- | --- |
| GET/POST `/api/studio/templates`, GET/PUT `/api/studio/templates/{id}` | Поиск, создание из saved block, detail и новая версия |
| POST `/api/studio/templates/{id}/versions/{versionId}/instantiate` | Независимая вставка выбранной версии |
| POST `/api/studio/templates/{id}/archive` | Архив/восстановление |
| GET/POST `/api/studio/media`, GET/PUT `/api/studio/media/{id}` | Поиск, upload, detail и метаданные |
| POST `/api/studio/media/{id}/versions`, POST `/api/studio/media/{id}/archive` | Новый файл/версия и архив/восстановление |
| GET `/media/owned/{assetId}/{versionId}` | Приватный файл своего владельца |
| GET `/media/participation/{sessionId}/{assetId}/{versionId}`, GET `/media/projection/{token}/{assetId}/{versionId}` | Только exact reference текущего этапа для участника/проектора |
| GET `/media/builtin/{versionId}` | Встроенная иллюстрация из manifest |

Записываемый документ содержит только `{assetId,versionId}`, разрешённые URL добавляются проекцией. Чужие ресурсы скрыты ответом 404; writes требуют CSRF и strict `expectedRevision` там, где меняется существующий ресурс. Подробные envelopes и фильтры — в [контракте этапа 4](docs/STAGE4_API.md).

## Аккаунт, история и репетиция — этап 6A

Регистрация, подтверждение email и восстановление пароля используют штатные Laravel notifications, signed URLs и password broker. Пароли не обрезаются и не нормализуются; сброс отзывает прежние authenticated sessions. Для production требуется действующий локальный sendmail, отправитель `lessons@atapin.de`; mail log/fakes не подтверждают доставку. При отказе транспорта приложение сообщает о проблеме и позволяет повторить подтверждение созданного аккаунта.

В аккаунт можно явно перенести все свои гостевые материалы, заготовки, изображения со старыми версиями и занятия. Перенос не меняет содержимое, ответы, идентификаторы или ссылки действующего занятия. Квота проверяется в общей транзакции; прежний гостевой доступ после переноса закрывается. Смена аккаунта блокирует открытые вкладки до загрузки текущего кабинета, сохраняя границы владения.

История `/ru/history` и `/de/history` разделяет реальные занятия и репетиции. Незавершённое занятие можно продолжить; «провести снова» создаёт чистый запуск той же фиксированной версии. Частные заметки, избранное и просмотр авторских версий не меняют выпущенное содержание. Репетиция создаёт отдельный неизменяемый снимок сохранённого материала, использует тот же runtime и даёт владельцу ученический/проекторный preview; обычный код и bearer-ссылка не открывают её посторонним.

Сроки проверяются при чтении независимо от cleanup: завершённые гостевые занятия и подробные данные учеников — 30 дней от завершения, история аккаунта без подробностей — 2 календарных года, завершённые репетиции — 7 дней от создания, command receipts — 30 дней. Активные реальные занятия и legacy finished без известной даты завершения защищены. Материалы, медиа, заготовки и permanent claim receipts не удаляются этой политикой. `php artisan lessons:retention --dry-run` показывает counts без записи; CLI и queue job очистки реализованы, автоматический schedule пока не включён. Контракт и ограничения — [STAGE6_API.md](docs/STAGE6_API.md).

Перед production migrations `deploy-plesk.sh --migrate` выполняет `lessons:backup`: приватный bundle полной БД и всех сохранённых private media versions с manifest/SHA256. Ошибка dump или целостности изображения блокирует migrations; источники и прежние backups сохраняются. SQL-only `lessons:database-backup` не резервирует изображения. Создание bundle не означает проверенное восстановление; условия и команды — в [руководстве deployment](docs/DEPLOYMENT.md).

## Конструктор и рабочие переводы — этап 6B

Конструктор сохраняет правки автоматически после паузы ввода, различает сохранение, ошибку, потерю связи и конфликт другой вкладки. Неопределённый результат повторяется с тем же UUID и телом; сервер подтверждает применённую редакцию. Новые правки во время запроса остаются в очереди. Undo/redo до 100 шагов относится к локальному содержанию и не отменяет опубликованные версии, файлы или команды занятия.

Язык содержания добавляется с пустыми переводимыми строками и прежними стабильными ID; готовность вычисляет сервер. Private partial drafts можно сохранить и просмотреть для ведущего, ученика и общего экрана. Выпуск, запуск и репетиция используют фактически готовые переводы с готовым основным языком; прежний строгий baseline не подменяет незавершённый черновик. Блоки и этапы копируются как независимые экземпляры. Раскладки вертикальная, две колонки и материал над заданием используют общий renderer, сохраняют порядок и складываются в одну колонку на узком экране.

Save receipts хранятся 30 дней и очищаются тем же ограниченным retention workflow; постоянные security receipts переноса аккаунта сохраняются. Контракт и сценарии приёмки — [STAGE6_EDITOR_API.md](docs/STAGE6_EDITOR_API.md); фактически выполненные проверки и production commit — в [PROJECT_STATUS.md](PROJECT_STATUS.md).

## Совместное проведение — этап 7

Владелец открывает раздел совместного проведения в пульте, создаёт приглашение и передаёт полученную ссылку соведущему. Страница `/{locale}/teacher-invitations#token=UUID` принимает приглашение и открывает отдельный пульт `/{locale}/conduct/{sessionId}`; компактный пульт и проектор доступны по `/control` и `/projector` относительно этого адреса. Приглашённый видит заметки ведущего, решения и ответы участников, поэтому доступ следует передавать только доверенному человеку.

Соведущий получает доступ только к этому занятию, без кабинета, авторских материалов и истории владельца. Владелец явно передаёт ведение, возвращает его себе или отзывает доступ; приглашение и выданный доступ отзываются отдельно. Соведущий может модерировать ответы, пока ведёт другой учитель. Проверки отзыва, истечения срока и текущего ведущего выполняются на сервере при каждом чтении и действии; репетиции приглашения не поддерживают. Границы доступа и команды — [STAGE7_API.md](docs/STAGE7_API.md).

## Публичный каталог и публикации — этап 8

Каталог `/ru/catalog` и `/de/catalog` показывает только одобренные материалы. Карточка открывает содержание, цели, условия проведения и безопасный preview этапов. «Провести этот урок» создаёт собственную копию и подготовленное занятие; «Скопировать в мой кабинет» открывает независимый черновик для редактирования. Исходный опубликованный снимок остаётся неизменным.

В конструкторе кнопка «Предложения в каталог» позволяет подтверждённому аккаунту выбрать собственную выпущенную версию, заполнить название и описание для её фактических языков, справочники и продолжительность и отправить предложение на проверку. Личные черновики и private media не публикуются. Автор видит статус и причину возврата; исправленный документ требует нового выпуска и нового предложения. Одобрение фиксирует предложенную версию, даже если автор продолжил редактирование.

Административные страницы `/ru/admin` и `/de/admin` требуют подтверждённого аккаунта с действующим серверным правом администратора. Администратор проверяет этапы, заметки и решения, одобряет материал либо возвращает его с причиной; управляет видимостью каталога и двуязычными справочниками возраста, тем, аудитории и форматов. Стабильные ключи справочников не переименовываются. Скрытие публикации не меняет уже созданные копии и занятия.

Право администратора назначает доверенный оператор существующему подтверждённому аккаунту; регистрация и профиль не позволяют получить его самостоятельно:

```bash
php artisan lessons:grant-admin exact-existing-verified-email
php artisan lessons:grant-admin exact-existing-verified-email --revoke
```

Страницы `/ru/library` и `/de/library` разделяют личные и общие заготовки. Из конструктора общая библиотека вставляет серверную копию выбранной версии с новым ID и сохранённым происхождением, проверяя наличие всех языков материала. Администратор создаёт и обновляет общие блоки в том же редакторе типов — текст, изображение, обсуждение и все интерактивные упражнения — с полными RU/DE переводами, авторством и правами. Новая версия общей заготовки не заменяет прежние вставленные экземпляры; скрытие запрещает новые вставки. Общие публикации допускают только reusable builtin media.

Команда `php artisan lessons:install-neighbor` устанавливает первоначальную адаптацию v1 урока «Кто мой ближний?»: 13 этапов, 45 минут и восемь иллюстраций. Она сохраняется как immutable snapshot; после обновления каталога эту команду повторно не запускают. Для полного переноса управления OLD и методических материалов предусмотрены отдельные идемпотентные команды:

```bash
php artisan lessons:install-neighbor-docs && \
php artisan lessons:upgrade-neighbor
```

Первая добавляет проверенный план RU/DE и исходные русские PDF/PPTX к канонической v1 без изменения выпущенного документа. Вторая проверяет точный исходный receipt, добавляет immutable v2 с методическими материалами и перепривязывает существующую запись каталога, сохраняя скрытие и административное одобрение. Прежние пользовательские копии и занятия остаются на своих версиях; новое поведение получают новая копия или новый запуск из каталога. Карта 13 этапов и границы проверки — [LESSON_CONDUCTING.md](docs/LESSON_CONDUCTING.md); порядок команд — [OPERATIONS.md](docs/OPERATIONS.md). Контракты каталога, проверки публикаций, справочников и общей библиотеки — [STAGE8_API.md](docs/STAGE8_API.md).

## Резервирование и фоновые операции — этап 9

`lessons:backup` создаёт приватный SQL/media bundle с проверкой размеров, SHA256 и покрытия immutable media. `lessons:restore-test` допускает только пустую изолированную MariaDB `lessons_restore_test` с ограниченным аккаунтом в local/testing; production restore этой командой невозможен. Реальный dump/import, права восстановленных занятий и актуальные сроки хранения проверяются в Linux CI.

Ежедневные backup и bounded retention выполняются отдельными database queues. Они выключены по умолчанию; очистка требует подтверждённой проверки восстановления и сначала допускает dry-run. Backup, retention и deployment используют один приватный lock; migration failures оставляют maintenance. Администратор видит состояние расписания, числовые результаты и безопасные сведения об ошибках, без SQL, паролей и ученических ответов. Автоматическое удаление backup и внешнее копирование пока не включены.

Настройка Plesk minute tasks, отдельного worker для backup, включение согласованных gates и безопасный порядок восстановления описаны в [OPERATIONS.md](docs/OPERATIONS.md). Ограниченный HTTP load test запускается только на disposable Linux/MariaDB стенде; предварительный профиль 10×30 не является согласованной нагрузочной приёмкой — [LOAD_ACCEPTANCE.md](docs/LOAD_ACCEPTANCE.md).

## Общие упражнения — этап 5

Каждый интерактивный блок имеет собственное состояние: подготовлен → открыт → закрыт → результаты раскрыты. Закрытый блок можно открыть снова с сохранением ответов; после раскрытия повторного цикла пока нет. Прежний `core.single-choice@1` открыт по умолчанию для совместимости; новые оцениваемые упражнения и опрос открывает ведущий. Роли и сигналы доступны сразу. Пауза занятия блокирует ответы, пауза таймера — нет.

Письменный ответ сохраняет исходный текст. Ведущий отдельно одобряет редакцию и публикует её на проекторе анонимно; ученик получает только собственные ответы. Правка учеником снимает прежнее одобрение/публикацию. Poll показывает агрегаты после раскрытия. Вместимость ролей проверяется атомарно; реакцию на запрос вопроса отмечает ведущий. Заметки к блокам и решения сохраняются приватно. Unicode-лимит текста считается по символам, без тихого обрезания. Старые документы, snapshots и optionId API сохраняют совместимость; контракт — [STAGE5_API.md](docs/STAGE5_API.md).
