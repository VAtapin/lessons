# lessons.atapin.de

Платформа интерактивных уроков. Реализованы основа и минимальная цепочка этапа 2: редактор → сохранение → выпуск версии → занятие → проектор → ответ ученика. Конструктор использует общие блоки текста, изображения и вопроса с одним вариантом ответа; конкретные учебные темы добавляются позже.

Это промежуточный прототип. Регистрация, полноценная библиотека заготовок, загрузка файлов, таймер, отделяемый компактный пульт, соведущие, история завершённых занятий и каталог относятся к следующим этапам. Встроенное изображение выбирается по версии из доверенного manifest; uploader не имитируется.

## Технологии и среда

- Laravel 13, PHP `^8.4` (локально проверяемая целевая версия — 8.4.25).
- Vue 3, TypeScript и Vite 8; Node.js 22 (ограничение проекта — `>=22.12.0 <23`).
- Постоянное хранение материалов, версий, занятий, участников и ответов: MariaDB 10.6.23 на production, SQLite для локального запуска и тестов.
- Начальные словари интерфейса RU/DE задают языки UI, а не окончательный список языков содержания уроков.
- На production выбран Plesk с PHP 8.5.11 FPM и Node.js 22.23.3.

Локально нужны PHP 8.4 с требуемыми Laravel расширениями, Composer и Node.js 22. Используйте штатные команды и исполняемые файлы вашего окружения; абсолютные пути конкретной Windows-машины в инструкции не зашиты.

## Локальный запуск

Из корня проекта:

```bash
composer install
npm ci --ignore-scripts
cp .env.example .env
php artisan key:generate
php -r "file_exists('database/database.sqlite') || touch('database/database.sqlite');"
php artisan migrate
npm run build
php artisan serve
```

Приложение откроется по адресу, указанному Artisan (обычно `http://127.0.0.1:8000`). Используются файловые cache/session с блокировкой параллельных запросов одной сессии и синхронная очередь. Если PHP использует нестандартный `PHPRC`, запускайте `artisan serve --no-reload`, чтобы расширения были доступны дочернему серверу.

Кабинет: `/ru/studio` или `/de/studio`; присоединение ученика: `/ru/join` или `/de/join`. Прототип работает без регистрации. Материалы принадлежат текущей серверной cookie-сессии: после её истечения/удаления cookies восстановление доступа пока не предусмотрено. Новый материал создаётся на текущем языке UI; редактор сохраняет и редактирует переводы уже многоязычного документа, добавление нового языка интерфейсом появится позже.

Сохранение ручное и требует валидного полного документа. Выпуск фиксирует личную версию и не публикует её в каталоге. Занятие использует этот снимок независимо от последующих правок материала; переход назад сохраняет ответы. Ученик и проектор получают только публичное содержание активного этапа.
