# lessons.atapin.de

Платформа интерактивных уроков. Завершён этап 1: подготовлена основа Laravel-приложения и независимое доменное ядро для строгой проверки документов уроков, версий типов блоков и проекций содержания для разных аудиторий. Сейчас доступна только стартовая информационная страница.

Конструктор, проведение уроков, авторизация, медиатека и хранение файлов, совместное ведение занятий и публичный каталог пока не реализованы. Наличие доменных DTO и контракта данных не означает готовность этих функций.

## Технологии и среда

- Laravel 13, PHP `^8.4` (локально проверяемая целевая версия — 8.4.25).
- Vue 3, TypeScript и Vite 8; Node.js 22 (ограничение проекта — `>=22.12.0 <23`).
- Для будущего постоянного хранения выбрана MariaDB 10.6.23. Этап 1 базу данных не использует.
- Начальные словари интерфейса RU/DE задают языки UI, а не окончательный список языков содержания уроков.
- На production выбран Plesk с PHP 8.5.11 FPM и Node.js 22.23.3.

Локально нужны PHP 8.4 с требуемыми Laravel расширениями, Composer и Node.js 22. Используйте штатные команды и исполняемые файлы вашего окружения; абсолютные пути конкретной Windows-машины в инструкции не зашиты.

## Локальный запуск

Из корня проекта:

```bash
composer install
npm ci --ignore-scripts
cp .env.example .env
php artisan key:generate
npm run build
php artisan serve
```

Приложение откроется по адресу, указанному Artisan (обычно `http://127.0.0.1:8000`). Настройки этапа 1 используют файловые cache/session и синхронную очередь. БД не подключена для работы ядра; миграции сейчас запускать не нужно.

## Проверки
