# Кто мой ближний? / Wer ist mein Nächster?

Eight original byte-for-byte WebP files supplied by the project owner from
`OLD/kto-moi-blizhnii/assets/`. The owner explicitly requested their reuse as
lesson illustrations in lessons.atapin.de. Individual creators are not recorded;
no public-domain or third-party redistribution license is claimed.

Each illustration is an ordinary reusable builtin with a pinned `v1` identifier.
Replacing a published file in place is prohibited: future changes require a new
file/version identifier. The catalog installer includes each SHA256 in its source
receipt and refuses a changed source revision under the existing slug.

The RU/DE lesson is an original concise retelling and pedagogical adaptation of
Luke 10:25–37. It does not copy a complete copyrighted Bible translation. Teachers
may read their group's own Bible separately. The age range 8–14 and the audience
labels are editorial guidance for the new adaptation, approved by the owner;
they are not claims about the original source's age or class.
