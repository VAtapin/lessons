# 02. Простить — значит всё забыть?

Взрослые · 60 минут · Мф. 18:21–35

[Русский комплект](ru/README.md) · [Deutsche Materialien](de/README.md)

В комплекте: план, интерактивный сценарий, паспорт, подсказки ведущему, описание для сайта, пособие DOCX/PDF, презентация и иллюстрированная раздатка DOCX/PDF. Восемь отдельных иллюстраций в папке images. Исходные материалы для очного занятия; установка в каталог приложения выполняется отдельно.

Интерактивная версия RU/DE: `php artisan lessons:install-adult-forgiveness`, затем `php artisan lessons:check`. Восемь этапов / 60 минут. Отдельные опросы до и после, добровольные роли, шесть карточек, скрытые новые факты, раздельные ответы о вымышленных героях. Личный лист остаётся на бумаге. Полное чтение и сценарий — в плане ведущего. Исходные DOCX/PDF/PPTX доступны для скачивания.
