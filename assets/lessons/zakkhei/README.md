# Закхей. Можно ли исправить ошибку?

Возраст: 9–11 лет. Время: 45 минут. Библейская основа: Лк. 19:1–10.

Цель: помочь детям признать свой поступок, попросить прощения и предложить посильное исправление вреда на примере истории Закхея.

## Скачать комплект

- [Материалы и четыре изображения — ZIP](Zakkhei_Materialy_i_izobrazheniya.zip?raw=true).
- [Презентация PowerPoint — 12 слайдов](Zakkhei_Prezentaciya.pptx?raw=true).

Скачайте оба файла. В GitHub файл также можно открыть и нажать **Download raw file**.

## Содержимое архива

- `Zakkhei_Polnyi_urok.docx` и `Zakkhei_Polnyi_urok.pdf`: паспорт, поминутный план, подробный интерактивный сценарий с репликами ведущего, подготовка и подсказки учителю.
- `Zakkhei_Razdatka.docx` и `Zakkhei_Razdatka.pdf`: четыре карточки действий и рабочий лист участника.
- `Zakkhei_Opisanie_saita.txt`: короткое описание для страницы сайта.
- `images/01.png`–`images/04.png`: четыре ранее созданные иллюстрации в исходном качестве.

Номера 12 этапов сценария совпадают со слайдами презентации. Третий рисунок показывает предполагаемое выполнение обещания Закхея; в Лк. 19:8 передано само обещание.

## Иллюстрированные материалы

Иллюстрация есть на каждом слайде презентации. Все карточки и рабочие листы раздатки содержат рисунки. Число слайдов, заметки ведущего и номера страниц раздатки сохранены. Для обсуждений используются рисунки этого комплекта как повторяющиеся иллюстрированные фоны.
