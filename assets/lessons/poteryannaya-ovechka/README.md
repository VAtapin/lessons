# Потерянная овечка

Библейский урок для детей **5–7 лет**, **35 минут**, **Лк. 15:3–7**.

Цель: помочь детям понять заботу Бога о каждом человеке и радость о возвращении к Нему, научиться замечать другого и проявлять заботу конкретным действием.

## Что делают дети

- Замечают пропажу в игре «Одной не хватает».
- Узнают голос овечки и отвечают жестом.
- Вместе ищут овечку по двум подсказкам.
- Разыгрывают настольный театр с фигурками.
- Выстраивают и оживляют кадры истории.
- Помогают вымышленному герою начать примирение.
- В парах приглашают друга строить вместе и показывают конкретную помощь.
- Выбирают маленькое доброе дело на неделю.

Учитель читает все подписи. Дети могут отвечать словами или жестами. В притче сто овец; пять карточек — модель для игры. Места поиска и современные ситуации придуманы для занятия.
