# Когда мне страшно

Библейский урок для детей **10–12 лет**, **45 минут**, **Мк. 4:35–41**. Группа 6–20 участников.

Цель: помочь детям увидеть власть Христа в рассказе об укрощении бури, научиться обращаться к Богу и людям за помощью, выбирать посильное действие и поддерживать другого.

## Интерактивные задания

- Чтение полного рассказа, затем сценка: два ученика в лодке, участник с событиями и жесты волн всей группы.
- Восстановление четырёх событий в парах.
- Сортировка чувств и поступков для вымышленного героя.
- Шесть ситуаций: подготовка и поддержка, защита взрослого или уточняющий вопрос.
- Парные диалоги с понятной просьбой и сменой ролей.
- Переделка неудачной реплики в предложение поддержки другу.
- Короткие слова молитвы по желанию.
- Командная мастерская плана для Лены с проверкой первого шага.
- Личный лист с доступными взрослыми, конкретной просьбой и следующим действием.

Лист остаётся у ребёнка. Можно работать с вымышленным героем. Пары и команды выполняют задания одновременно. Презентация сопровождает очный разговор, сценку и работу с карточками.

## Подготовка

Страница 1 раздатки — каждому участнику; страницы 2 и 4 — каждой паре; страницы 3 и 5 — каждой команде. Дополнительно подготовьте один комплект событий для сценки. Карточки заранее разрежьте и перемешайте. Нужны два стула, карандаши, Библия или текст приложения и экран. Вариант без экрана проводится с распечатанными иллюстрациями.
