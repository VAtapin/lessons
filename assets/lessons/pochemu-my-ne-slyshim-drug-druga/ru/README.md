# Почему мы перестаём слышать друг друга?

Почему знакомые слова порой отдаляют нас друг от друга? Через сценку с неожиданным раскрытием обстоятельств, чтение Писания и практику слушания участники учатся проверять свои догадки, говорить о важном и договариваться. Два формата: урок для взрослых на 60 минут и занятие для одной или нескольких супружеских пар на 75 минут. Есть иллюстрированные презентации и материалы для печати.
