# Четверо друзей

Готовый очный урок для детей 9–11 лет, 45 минут, по Мк. 2:1–12. После полного чтения Евангелия сразу проводится сценка. Далее дети восстанавливают события, решают общую задачу, пробуют разговор о помощи и выбирают личное дело на неделю.

## Документы и материалы для печати

- Полное пособие, 11 страниц: [PDF](Chetvero_druzey_Polnyi_urok.pdf), [редактируемый Word](Chetvero_druzey_Polnyi_urok.docx).
- Иллюстрированная раздатка, 6 страниц: [PDF для печати](Chetvero_druzey_Razdatka.pdf), [редактируемый Word](Chetvero_druzey_Razdatka.docx).
- [PowerPoint](Chetvero_druzey_Prezentaciya.pptx): на каждом слайде отдельный рисунок, текст редактируется. Заметки содержат реплики, время, порядок проведения и ответы для учителя.

Раздатка содержит 18 карточек: 6 карточек ролей, 4 события, 4 разных сведения для команды и 4 ситуации. На каждой карточке есть иллюстрация. Общий план команды, оба парных разговора, личный лист и молитва тоже сопровождаются рисунками.

## Что и сколько печатать

| Страница раздатки | Количество |
|---|---|
| 1. Роли | Один комплект. Карточка «Четверо друзей» предназначена четырём участникам |
| 2. События | Один комплект на пару, вырезать и перемешать |
| 3. Сведения и общий план | Один лист на команду из четырёх |
| 4. Ситуации | Один комплект на две пары |
| 5. Парные разговоры | Один лист на пару |
| 6. Личный шаг | Каждому участнику |

Библейский текст для чтения находится на странице 10 полного пособия и в заметках второго слайда. PowerPoint сопровождает очное занятие; ответы обсуждаются устно и записываются на бумаге.

В основных сценах ровно четыре помощника; человек на постели отдельно. Христос сначала объявляет прощение, затем исцеляет. Современные ситуации вымышлены. Изображённые кресты православные восьмиконечные.
