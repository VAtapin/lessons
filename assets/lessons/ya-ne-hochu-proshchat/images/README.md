# Серия иллюстраций

14 PNG созданы для урока. Библейские рисунки — художественные иллюстрации притчи; современные случаи вымышлены. Все суммы задаются текстом и таблицей, мешки на рисунке условны.

- 01. **Обида и расстояние** — Обложка, честное называние чувства.
- 02. **Чтение Евангелия** — Учитель читает весь ответ Христа.
- 03. **Сценка по притче** — Пять актёров, свидетель представляет товарищей.
- 04. **Царь прощает долг** — Два персонажа; мешки с имуществом условны.
- 05. **Отказ помиловать товарища** — Два должника, просьба и отказ.
- 06. **Чувства и действия** — Пары разбирают понятия по карточкам.
- 07. **Четыре сведения** — Команда готовит помощь Соне.
- 08. **Разговор об обиде** — Честная просьба и признание поступка.
- 09. **Помощь взрослого** — Прекращение повторяющегося вреда.
- 10. **Личный первый шаг** — План на неделю остаётся у подростка.
- 11. **Молитва, когда трудно** — Православный восьмиконечный крест.
- 12. **Исправление и доверие** — Восстановление повреждённой записи делом.
- 13. **Строгий ответ царя** — Возвращение должника и укор в немилосердии.
- 14. **Начало расчёта** — Большой долг перед царём, до прощения.
